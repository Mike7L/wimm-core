# Первая публикация Wimm в Chrome Web Store

Войдите в [панель разработчика](https://chrome.google.com/webstore/devconsole/) как владелец карточки. Если издатель ещё не зарегистрирован, Google может запросить регистрацию, данные владельца, включение двухфакторной аутентификации и оплату регистрационного сбора.

Загрузите ZIP из GitHub Releases с manifest.json в корне. После создания карточки сохраните её идентификатор. Для последующих выпусков используйте эту же карточку.

## Материалы

- Язык — русский. Подходящая категория — продуктивность.
- Название берётся из manifest.json: «Wimm — голосовой блокнот».
- Описание: «Записывайте голос и сохраняйте заметки, файлы и снимки страниц. Ищите по расшифровкам на русском. Голосовая помощница Алёна находит записи, а секретарь Claude по вашему запросу собирает из выбранных источников Markdown-документ со ссылками. Русское распознавание работает на устройстве. Для функций Claude нужен собственный API-ключ Anthropic.»
- [Скриншот 1280 × 800](store-1280x800.png), [промоизображение 440 × 280](store-440x280.png), иконка 128 × 128 в extension/icons.
- [Публичная политика конфиденциальности](https://github.com/Mike7L/wimm-core/blob/wimm-browser/docs/privacy.md).
- Для проверки записи, поиска и импорта ключ не нужен. Рецензент может разрешить микрофон, сделать запись и сказать «Алёна, найди бумагу». Для проверки секретаря нужен ключ Anthropic с доступом к указанной в настройках модели. Не включайте ключ в сборку.

## Назначение и разрешения

Единое назначение — сохранение и последующая работа с личными заметками, включая расшифровку и создание личного документа из выбранных источников.

| Разрешение | Назначение |
| --- | --- |
| activeTab | Снимок видимой области активной страницы после нажатия пользователем и адрес источника |
| contextMenus | Сохранение выделенного текста со страницы |
| storage | Настройки распознавания, название модели и временный API-ключ |
| unlimitedStorage | Локальная библиотека крупных аудиозаписей, документов и изображений |
| offscreen | Обработка очереди с помощью локальных движков в фоновом документе, когда блокнот закрыт |
| alarms | Возобновление незавершённой очереди после приостановки фонового процесса Chrome |
| api.anthropic.com | Обращения к Claude по команде пользователя с его API-ключом |

Весь исполняемый JavaScript, WebAssembly и модели Vosk и Tesseract включены в ZIP. Раздел «Privacy practices» заполняется владельцем с учётом фактически обрабатываемых данных, в том числе содержимого страниц, пользовательских заметок, записей и аутентификационной информации. Выберите видимость карточки и отправьте на проверку. Автообновления начинают распространяться через магазин после одобрения и публикации.
