# Wimm для Chrome и Edge

Расширение Manifest V3 на JavaScript. Заметки, аудиозаписи, скриншоты и личный документ хранятся в профиле браузера. Русская модель Vosk входит в архив. Для установки и записи не нужны Node.js, сервер или подписка Claude.

## Установка

1. Распакуйте архив в постоянную папку.
2. Откройте `chrome://extensions` в Chrome или `edge://extensions` в Edge и включите режим разработчика.
3. Нажмите «Загрузить распакованное расширение» и выберите папку с `manifest.json`. Закрепите значок Wimm на панели браузера.

## Запись и импорт

- Нажмите значок Wimm для быстрой текстовой заметки. Выделенный на странице текст можно сохранить через контекстное меню.
- «Запись голоса» открывает вкладку блокнота. При первом запуске разрешите микрофон. Можно переключаться на другие вкладки, пока вкладка блокнота открыта. Нажмите «Завершить запись». Звук сохраняется частями. После аварийного закрытия Wimm при следующем открытии собирает успевшие сохраниться фрагменты.
- Для снимка откройте нужную страницу, нажмите значок расширения и «Снимок вкладки». В библиотеке появится PNG видимой части страницы с адресом источника. Для локальных страниц браузер может потребовать включить доступ к файловым URL в параметрах расширения.
- В библиотеке нажмите «Импорт файлов» или перетащите файлы на панель записи и импорта. Исходные форматы Wimm включают M4A, MP3, WAV, AIFF, AIF, CAF, FLAC, AAC, Opus, OGA, OGG, PDF, PNG, JPG/JPEG, HEIC, GIF, WebP, TXT, MD, Markdown, LOG, CSV, TEXT, DOCX и DOC. Также принимается WebM. Каждый файл сохраняется отдельной заметкой с оригиналом для скачивания.
- Вместе с файлом можно выбрать одноимённый Wimm-файл метаданных `.meta.json` или `.metadata.json`. Расширение прочитает заголовок, сохранённый транскрипт и текст вложений. Для TXT и Markdown приоритет имеет содержимое самого файла.
- Текст DOCX извлекается при импорте. Для старых DOC, HEIC или аудиокодеков, которые браузер не декодирует, доступны оригинал и ручное добавление текста.

## Очередь и значок расширения

Заметки без текста попадают в очередь автоматически, в том числе сохранённые в версии 1.0.0. Аудио расшифровывается на русском. Из изображений и скриншотов извлекается русский и английский текст. В PDF Wimm читает текстовый слой, а страницы без него распознаёт как сканы. Распознавание продолжается при закрытом блокноте, пока работает Chrome. После перезапуска браузера очередь возобновляется.

В разделе «Очередь» видны ход обработки, результаты и ошибки. Нажмите название, чтобы открыть оригинал и текст. Кнопка «Повторить» запускает обработку ещё раз. Изменения, сделанные вручную во время распознавания, сохраняют приоритет.

Закрепите Wimm в меню расширений Chrome. Во время записи сам значок показывает уровень звука, при наведении — длительность. В обычном режиме число показывает размер очереди, а знак «!» указывает на ошибку. Для остановки записи откройте значок и нажмите «Стоп».

## Алёна

Начните запись и скажите «Алёна, найди бумагу». После паузы или нажатия «Завершить запись» Wimm сохранит звук, проверит финальное распознавание и откроет поиск. Допускаются «Алена» и «Эй, Алёна». При отключённом распознавании команду можно ввести на вкладке «Алёна».

«Алёна, запусти секретаря» запускает подготовку черновика по отмеченным источникам в разделе «Секретарь». На другие вопросы отвечает Claude. Он получает текст текущего обращения, недавнюю и подходящие заметки и фрагмент личного документа. Ответ отображается в блокноте и по выбору озвучивается системным голосом. После ответа новую запись можно начать вручную.

## Секретарь Claude

1. В настройках введите ключ Anthropic API с доступом к Messages API. Ключ хранится в памяти браузерного сеанса. Модель по умолчанию — `claude-sonnet-4-6`. Её можно заменить на доступный вашему аккаунту идентификатор.
2. В «Секретаре» отметьте источники и нажмите «Подготовить черновик». В Anthropic отправляются выбранный текст, распознанные расшифровки, поддерживаемые изображения, PDF и текущий личный документ. Генерация оплачивается по тарифу вашего API-аккаунта.
3. Проверьте Markdown и ссылки, внесите исправления и нажмите «Добавить в документ». Щелчок по ссылке в разделе документа открывает исходную заметку. Документ можно скачать в формате Markdown.

Запись, распознавание, импорт, поиск и снимки работают без ключа и без сети. Удаление расширения очищает его хранилище. Оригиналы можно скачать из карточек, личный документ — из раздела «Документ».
