# Wimm для Chrome

Голосовые заметки с локальным распознаванием русской речи, снимками вкладок, импортом файлов, Алёной и секретарём Claude. Аудио, скриншоты и PDF без текста обрабатываются в фоновой очереди. Закреплённый значок показывает запись и число ожидающих заметок. Личный документ открывается в отдельном режиме чтения с оглавлением и ссылками на источники. Ветка `wimm-browser` содержит исходный код расширения Manifest V3.

## Установка

**ZIP для разработчика.** Распакуйте ZIP в постоянную папку. Включите режим разработчика на `chrome://extensions`, выберите «Загрузить распакованное расширение» и укажите папку с `manifest.json`. Для ручного обновления замените файлы в той же папке и нажмите ↻ на странице расширений.

**Автоматическое обновление на Windows и macOS.** Для обычной установки Google Chrome требуется версия из Chrome Web Store. После первой публикации установите Wimm из его карточки. Следующие одобренные версии Chrome будет получать автоматически, когда браузер проверяет обновления. Уже распакованная копия остаётся отдельной установкой, со своей локальной библиотекой. Перед переходом сохраните нужные записи из её карточек и скачайте личный документ.

## Выпуск версии

1. Увеличьте `version` в `extension/manifest.json`. Запустите `python3 tools/package.py` (Python 3.9+). Сборка помещает ZIP и контрольную сумму в `dist/`.
2. Для первого выпуска создайте карточку в панели издателя Chrome Web Store и загрузите ZIP. Материалы карточки, скриншот и описания разрешений находятся в [инструкции для издателя](docs/store.md).
3. Для обновления загружайте ZIP с увеличенной версией **в ту же карточку** и отправляйте на проверку. Браузер получит версию после её публикации. Та же сборка может распространяться в GitHub Releases для ручной установки.
