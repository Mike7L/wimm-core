# Конфиденциальность Wimm для Chrome

Заметки, аудиозаписи, снимки, импортированные файлы, распознанный текст и личный документ хранятся в IndexedDB профиля браузера. Распознавание аудио и текста на изображениях, а также чтение PDF выполняются на устройстве, в том числе в фоновом режиме. Речевые и текстовые модели входят в пакет. Для снимка Wimm запрашивает доступ к активной вкладке по действию пользователя. Вместе со снимком сохраняются её заголовок и адрес. При сохранении выделения через контекстное меню сохраняются текст и адрес страницы.

При запуске секретаря расширение отправляет напрямую на api.anthropic.com текст отмеченных источников, их идентификаторы, доступные адреса источников, изображения поддерживаемых форматов, PDF и текущий личный документ. Звуковые файлы обрабатываются локально, секретарю передаётся их имеющийся текст. Вопрос к Алёне через Claude включает само обращение, текстовый контекст недавних и подходящих заметок и часть личного документа. Команда поиска выполняется локально. Озвучивание ответа использует службу синтеза речи браузера или операционной системы.

Для запросов Claude используется API-ключ пользователя. Он хранится в chrome.storage.session до завершения браузерного сеанса. Его можно удалить в настройках Wimm. При использовании API действуют условия и правила обработки данных Anthropic. В сборке отсутствуют собственный сервер сбора данных, рекламные SDK и аналитика использования.

Чтобы сохранить материалы, скачайте оригиналы из карточек и экспортируйте личный документ. Удаление расширения удаляет его хранилище из профиля. Обратная связь по расширению доступна через GitHub Issues проекта. Не публикуйте там личные записи или ключи.
